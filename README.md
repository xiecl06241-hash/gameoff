# SHIFT / 24 — 便利店夜班恐怖游戏

**这是《SHIFT / 24》的 Unreal Engine 游戏工程源码仓库。** 项目围绕 GitHub Game Off 2026 的 **SHIFT** 主题制作：你扮演便利店夜班店员，完成整理、补货、收银和打扫工作，在伪装成顾客的怪物袭击下保持清醒。怪物显形时，店铺的货架布局与照明会发生异常转变。

当前版本是 **Windows 第一人称 3D、三晚流程的可玩原型（MVP）**，使用 **Unreal Engine 5.8.2**，支持英语、日语、繁体中文和简体中文。仓库包含 C++ 玩法代码、模型与材质、语言包、资产生成工具及验证记录；七晚完整内容仍属于后续计划。

**This is the Unreal Engine source repository for SHIFT / 24**, a first-person convenience store night-shift horror game for GitHub Game Off 2026. The current Windows prototype contains three playable nights. **SHIFT** means both working the night shift and the store physically shifting when an entity reveals itself.

## 快速启动 / Quick Start

**[下载 v0.3 Windows 免安装版](https://github.com/xiecl06241-hash/gameoff/releases/download/v0.3/ShiftStore-v0.3-Windows-x64.zip)** · [版本说明与已知问题](Docs/RELEASES/v0.3.md)

**先确认你拿到的是打包版还是源码。** `Builds/` 被 Git 忽略，**克隆本仓库或下载 GitHub 的 Source code ZIP，都不会附带 `ShiftStore.exe`**。下面的启动文件在本机完成打包后，或拿到独立 Windows 打包版后才会存在。

### 已有 Windows 打包版：直接玩

1. 将打包版**完整解压**到一个文件夹，保留所有子目录。
2. 在解压后的 `Windows` 目录中双击 **`ShiftStore.exe`**；也可双击同目录的 **`启动正常场景.cmd`**，以 **1920×1080 全屏**启动。开发工作区中的对应位置是 **`Builds/Windows/ShiftStore.exe`**。
3. 选择语言：**1 English／2 日本語／3 繁體中文／4 简体中文**。点击选项，或按数字键选择后按 `Enter` 确认。
4. 标题页按 **`Space`／`E`／`Enter` 开始新游戏，从第一晚开始**；按 **`C` 继续已有存档**。进入夜晚说明页后，再按 `Space`／`Enter` 开始操作。
5. 使用 **WASD 移动、鼠标观察、E 交互或长按做任务**。看**右上角的当前目标和操作步骤**，沿黄色箭头到达工作点，再对准高亮目标交互。按 **Tab** 切换任务指引。按 **Esc** 打开暂停菜单，可继续游戏、调整鼠标灵敏度、返回主菜单或退出。

试玩打包版无需安装 UE、Visual Studio 或 Python。**不要只复制单个 EXE**，游戏还需要同目录下的 `ShiftStore/`、`Engine/` 等配套文件。

**For players:** extract the entire Windows build, then run `Windows/ShiftStore.exe` or `Windows/启动正常场景.cmd`. Select a language, then press `Space` / `E` / `Enter` for a new game at Night 1, or `C` to continue. Keep the entire build folder together. UE and Python are not required to play. A source checkout does **not** include the executable; see the build instructions below.

### 只有源码：编译并启动

开发环境需要 **Windows x64、UE 5.8.2、Visual Studio 2022（C++ 游戏开发工具及 Windows SDK）、Git、Git LFS 和 Python 3**。Python 用于构建辅助脚本，玩家运行打包版不需要它。

在 **Git Bash** 中克隆并下载完整二进制资产：

```bash
git lfs install
git clone https://github.com/xiecl06241-hash/gameoff.git
cd gameoff
git lfs pull
```

已有本地仓库时，直接进入含 `ShiftStore.uproject` 的目录，执行 `git lfs pull` 即可。优先使用 Git 克隆，以确保 UE 模型、地图和字体已下载为真实资产。

**方式 A：在 UE 编辑器中试玩**

1. 双击根目录的 **`ShiftStore.uproject`**，使用 UE **5.8.2** 打开；首次打开如提示编译缺失模块，选择编译。
2. 默认打开 `Normal` 地图；若打开了其他地图，在内容浏览器进入 `Content/ShiftStore/Maps`，打开 **`Normal`**。
3. 点击编辑器顶部 **Play（运行）**，建议选择 **Standalone Game（独立游戏）**，然后按前面的语言选择、新游戏步骤进入。

**方式 B：生成可独立运行的 Windows 版本**

关闭该工程的 UE 编辑器，在仓库根目录的 Git Bash 执行以下命令。将 `UE_ROOT` 改成自己的 UE 安装目录，目录下应包含 `Engine/`：

```bash
export PYTHONUTF8=1 PYTHONIOENCODING=utf-8
export UE_ROOT='D:/UE/UE_5.8'
python .github/scripts/build_windows.py --check-only
python .github/scripts/build_windows.py
```

脚本会编译编辑器模块、打包游戏并生成启动脚本。成功后打开 **`Builds/Windows/ShiftStore.exe`**，或在 Git Bash 执行：

```bash
./Builds/Windows/ShiftStore.exe
```

仓库已包含生成好的场景与模型，正常编译试玩无需重新生成环境资产。构建输出和日志分别位于 `Builds/Windows/` 与 `Saved/QA/`。

## English Overview (For Game Off 2026 Judges & Players)

### How to Play
1. Launch the complete Windows build as described in [Quick Start](#快速启动--quick-start). In a developer workspace, the executable is **`Builds/Windows/ShiftStore.exe`**; it is generated by packaging and is not included in Git.
   Choose **1 English**, **2 日本語**, **3 繁體中文**, or **4 简体中文** before the title screen. Click a language or select it with arrows / `1`–`4` and press `Enter`. Your choice is remembered; press `L` on the title screen to change it.
   `Space` / `E` starts a **new game at Night 1**. Use `C` to explicitly continue an existing save.
2. Complete your assigned clerk chores before their timers expire—overdue tasks steadily drain your **Sanity**.
3. Once all active chores are finished, a customer enters the store (only one customer is inside at a time):
   - **Normal Customers** browse, occasionally ask you to fetch a specific product (`[E]` to pick up from a shelf and `[E]` to hand it over), and pay at the **Checkout Register** (`[E]`).
   - **Abnormal Entities** disguise themselves as customers and reveal themselves while you are fetching an item. When they reveal, **the entire store automatically SHIFTS**: middle gondolas slide 30 cm, main ceiling lights cut out leaving only cold-storage and exit lights, and a displaced item begins glowing red somewhere in the store.
   After the customer leaves, one chore is assigned: shelf tidying and oden preparation alternate, with a batch restock only after three paid sales. The last customer leads directly to dawn cleanup.
4. **Banishing an Entity**: Find the item the entity demands and deliver it to the **Checkout Register** (`[E]`) while avoiding or looping the entity around shelves.
   - Throwing merchandise (`[F]` or `Right Mouse Button`) stuns the entity temporarily (each product has a distinct wholesale cost and stun duration), or you can grab a hot cup from the **Oden Station** for a heavy stun.
   - Destroyed merchandise is deducted at wholesale cost from store revenue; exceeding the loss limit (`-$40`) terminates your run.
   - If grabbed, hold/mash `[E]` to struggle free slowly, or press `[F]`/`[RMB]` while holding a product to smash the entity and break free immediately.
5. After all customers for the night are served, equip the **Mop** in the back corridor, clean the floor spills, and survive until **06:00 AM Dawn**. Progress auto-saves after each night (3 nights total).

### Controls
| Key / Input | Action |
| --- | --- |
| `W` `A` `S` `D` | Move |
| `Mouse` (or Arrow Keys) | Look |
| `E` or `Left Mouse Button` | Interact / Pick up item / Hold to complete chore / Ring up / Struggle |
| `F` or `Right Mouse Button` | Throw held item (stuns entity on hit) |
| `G` | Drop held item |
| `Space` / `Enter` | Advance Title / Night Intro / Dawn screens |
| `R` | Restart current night from auto-save (on Game Over screen) |
| `Alt + F4` | Quit |
| `Esc` | Pause / resume; menu supports mouse, Up/Down or W/S, and Enter/Space |
| `L` (title screen) | Change language |
| `C` (title screen) | Continue saved game |
| `Tab` (during chores) | Guide to the next chore |

Pausing freezes chores, sanity loss, customers, monsters and world physics. Returning to the title discards unsaved progress from the current night; the last dawn checkpoint is preserved.

Open **Esc → Mouse Sensitivity** to adjust camera speed with the slider or Left/Right keys. The range is **0.10–3.00×**, with **1.00×** preserving the original speed. Changes are saved automatically; **Restore Default** resets to 1.00×. Esc returns to the pause menu before resuming. This adjusts in-game sensitivity; hardware DPI remains a mouse-driver setting.

## 中文说明（玩法、工程与构建指南）

### 1. 直接试玩
启动文件、源码编译和进入第一晚的完整步骤见文档开头的 [快速启动](#快速启动--quick-start)。会记住上次语言选择，标题页按 `L` 可重新选择；语言设置与夜晚进度存档独立。

日常任务有常驻步骤和黄色通道／距离标记，按 `Tab` 可切换指引的任务。当前三晚每项任务时限分别为 **240／180／120 秒**，夜晚说明页暂停计时。补货时先沿标记去仓库领取补货纸箱，再跟随新标记回到货架长按 `E`。

夜晚中按 `Esc` 打开暂停菜单，再按 `Esc` 继续；也可用鼠标点击，或方向键／W、S 选择后按 Enter／Space 确认。暂停时任务倒计时、清醒度扣除、顾客／怪物及物理运动均停止。返回主菜单会放弃本晚未保存的进度，保留最近一次天亮时的存档。

进入 **Esc → 鼠标灵敏度**，拖动滑条或用左右方向键调整，范围为原速度的 **0.10–3.00 倍**，默认 **1.00 倍**；“恢复默认”可还原。设置自动保存，重启游戏仍有效，与语言及夜晚存档独立。设置页按 Esc 返回暂停菜单，再按 Esc 继续游戏。此项调整游戏内视角速度，鼠标硬件 DPI 仍在鼠标驱动中设置。

界面、任务、交互提示、顾客对白、失败与结算文字均支持上述四个语言选项。场景中的原创品牌、包装和实体标识暂保留原样。语言包和字体制作说明见 [Docs/LOCALIZATION.md](Docs/LOCALIZATION.md)。

### 2. 核心玩法与完整流程（3 晚 MVP）
- **日常店员任务与清醒度（Sanity）**：每项补货（从仓库取货箱 `Stock Carton`）、清点、整理、倒垃圾任务都有独立倒计时；逾期会持续扣除清醒度，完成后停止扣除并部分恢复清醒度。
- **顾客进店与服务优先级**：只有当前待办任务全部完成且店内无残留顾客/怪物时，下一位顾客才会进店（同时仅 1 位在店）。帮求助顾客找到指定商品（按 `E` 拿取并按 `E` 递交），并在收银台按 `E` 结账获得营业收入。
- **怪物显形与店铺自动转变（Shift）**：异常顾客会在你帮忙找商品时显形；显形瞬间**同一家便利店在运行时平滑转入 Shift 异常状态**（中排货架横移 30 cm、主照明熄灭仅留冷柜与出口灯、欢迎牌变为异常告示，同时刷出泛红光的异常需求商品）。若未目击显形，怪物会潜伏偷袭，抓到玩家时额外一次性扣除大段清醒度。
- **反制、挣脱与店铺亏损（Loss Limit）**：把异常顾客要求的商品送到收银台即可驱离怪物并让店铺恢复正常。期间可用商品或关东煮热汤（`F` 或鼠标右键投掷）砸晕怪物争取时间；损坏的商品按成本价计入负收入，累计亏损达到 `-$40` 或清醒度归零即淘汰。被抓时可按住/连按 `E` 缓慢挣脱，或手持商品按 `F`/`右键` 直接砸晕快速挣脱。
- **夜末打扫与自动存档**：服务完当晚全部顾客后，去后勤走廊拿起拖把（`Mop`）清理地面污渍，按 G 放下拖把，再将散落商品拾起并对准货架按 E 放回。全部收好即可迎来 `06:00 AM` 天亮并自动存档；失败可按 `R`/`Space` 回溯至当晚开头。

### 4. 回归检查

完成 Windows 打包后，在 Git Bash 的工程目录运行 `python Tools/check_gameplay.py`。脚本会启动两个隔离的独立包进程：正常用例必须返回 0，故意注入失败的用例必须返回 1，且两次运行前后的玩家存档内容必须保持一致。

自检覆盖：顾客模型与动画的打包加载、真实物理投掷命中、成本扣款、首夜及后续夜晚的账本回滚、GC 后的告示保活、跨帧验证货架与实例商品位置／灯光／告示切换和恢复、闪灯结束恢复，以及专用存档槽的读写与清理。它不等同于完整的人工通关验收。

自检需要专用进程参数 `-ShiftSelfTest -ShiftSelfTestExit`；正常游玩进程中的 `ShiftRunSelfTest` 命令会拒绝执行，避免破坏当前夜晚。自检只使用随机命名的 `ShiftStoreSelfTest_*` 存档槽，并在结束时清理。原始报告和日志位于 `Saved/QA`，可分享的结果位于 `Verification/gameplay_selftest*.json`。

# SHIFT / 24 v0.2

Windows x64 三晚试玩原型，UE 工程版本为 0.2.0。保留英语、日语、繁体中文和简体中文支持。

## 下载与启动

1. 下载 Release 附件 **ShiftStore-v0.2-Windows-x64.zip**，完整解压并保留所有子目录。GitHub 自动生成的 Source code 压缩包是源码，不含游戏 EXE。
2. 双击 **Windows/ShiftStore.exe**，或 **Windows/启动正常场景.cmd**（1920×1080 全屏）。这是免安装版，无需安装 UE、Python 或开发工具。
3. 选择语言后，在标题页按 Space／E／Enter 从第一晚开始，C 继续已有存档。
4. WASD 移动、鼠标观察、E 交互或长按做任务、Tab 切换任务指引、F／右键投掷、G 放下物品。
5. **Esc** 打开暂停菜单；在 **鼠标灵敏度** 中拖动滑条或使用左右方向键调整。范围 **0.10–3.00 倍**，默认 **1.00 倍**，可恢复默认并自动保存。设置页 Esc 返回暂停菜单，再按 Esc 继续。

如提示缺少 Visual C++ 运行库，可运行包内 `Windows/Engine/Extras/Redist/en-us/vc_redist.x64.exe`。升级前请退出游戏并备份旧版 `Windows/ShiftStore/Saved/`（如果存在）；本包不附带玩家存档或本机设置。SHA-256 校验值见附件 `SHA256SUMS.txt`。

## 相比 v0.1 的变化

- 增加 Esc 暂停、继续、返回主菜单和退出功能，暂停期间冻结任务、清醒度扣除及怪物行动。
- 增加四语言鼠标灵敏度设置，调整水平／垂直视角速度，跨重启保存；不影响鼠标硬件 DPI、语言偏好或夜晚检查点。
- 任务与步骤合并到右上区域，加入地面路线箭头、屏幕方向提示、到达高亮及路线不可达提示。
- 抓取视角对准怪物头部并收紧 FOV，挣脱后恢复；加入低频主角情境字幕。
- 接入顾客挡路检测和让路台词；这部分仍有待验收的问题，见下节。

## 验证与已知问题

- Windows 打包、52 项玩法回归通过；故意失败用例按预期返回非零退出码，正式存档未变。
- 四语言 720p／1080p 的灵敏度设置各 20 项检查通过，包含实际 yaw／pitch 倍率及独立进程重启读取；四语言暂停菜单各 19 项检查通过。
- **顾客被玩家挡路时的停止／让路提示专项回归尚未通过，相关行为可能不稳定。** 本版本不宣称五项试玩反馈已经全部验收。
- 当前仍为三晚原型，完整七晚、最终怪物脸部美术及完整人工通关验收属于后续内容。更详细的验证范围见 [VERIFICATION.md](../../VERIFICATION.md)。
- `v0.1` 的下载附件保留原发布内容。

## English quick start

Download **ShiftStore-v0.2-Windows-x64.zip**, extract the entire archive, and run **Windows/ShiftStore.exe**. No Unreal Engine, Python or development tools are needed. Select a language, then press Space / E / Enter for a new game or C to continue.

Press **Esc** to pause. Open **Mouse Sensitivity** to adjust camera speed from **0.10× to 3.00×**; changes are saved automatically. The default **1.00×** preserves the original speed. Esc returns from settings to the pause menu before resuming.

This three-night prototype adds the pause menu, persistent sensitivity settings, consolidated objectives, layered navigation and head-focused grab reactions. **Customer obstruction / courtesy behavior still has failing targeted regression cases and may be unreliable.** Existing gameplay and menu checks do not replace a complete manual playthrough. Keep the whole build folder together; automatic Source code downloads are not the playable game.

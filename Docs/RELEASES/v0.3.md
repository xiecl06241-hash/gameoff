# SHIFT / 24 v0.3

Windows x64 三晚试玩版，支持英语、日语、繁体中文和简体中文。

## 下载与启动

下载 **ShiftStore-v0.3-Windows-x64.zip**，完整解压后双击 **Windows/ShiftStore.exe**。选择语言，在标题页按 Space、E 或 Enter 从第一晚开始。按 C 可读取已有进度。如系统提示缺少运行库，包内附有 `Windows/Engine/Extras/Redist/en-us/vc_redist.x64.exe`。文件校验值见同页的 `SHA256SUMS.txt`。

升级时先保留旧版目录。若旧存档位于旧包的 `Windows/ShiftStore/Saved/SaveGames`，可在游戏关闭时将其复制到新版对应目录。

## 本版变化

- 拿错普通商品时，对准货架或冷柜按 E 即可放回。双手已满会显示提示。按 G 放下物品，F 或鼠标右键投掷。贴近薄墙或货架时，商品会从玩家这一侧释放。
- 打烊时，拖完地后按 G 放下拖把，再把散落的普通商品一件件收回货架。右上角显示剩余数量，最后一件归架后天亮并自动存档。
- 煮关东煮的长按 E 交互点移至玻璃罩正上方。
- 怪物追逐时会沿货架通道绕开障碍。卡住检测按一段时间内的实际位移判断，可在高帧率下正常绕行。

## 试玩范围

本版开放三晚。自动流程覆盖顾客进出店、异常显形、打烊和第三晚结局，其中部分交互由脚本完成。首次玩家能否独立看懂引导，以及全新 Windows 电脑的首次启动体验，仍待人工验收。

## English quick start

Extract **ShiftStore-v0.3-Windows-x64.zip** and run **Windows/ShiftStore.exe**. Choose a language. Press Space, E or Enter for a new game, or C to continue. Return a held product by aiming at a shelf and pressing E. After mopping, press G to drop the mop and put away any loose merchandise to finish the night.

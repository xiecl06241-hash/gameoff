# SHIFT / 24 v0.5

Windows x64 三晚试玩版，支持英语、日语、繁体中文和简体中文。

## 下载与启动

下载 **ShiftStore-v0.5-Windows-x64.zip**，完整解压，双击 **Windows/ShiftStore.exe** 或 **Windows/启动正常场景.cmd**（1080p 全屏）。选择语言后，按 Space、E 或 Enter 从第一晚开始，按 C 继续已有存档。如提示缺少 Visual C++ 运行库，可运行包内的 `Windows/Engine/Extras/Redist/en-us/vc_redist.x64.exe`。附件 `SHA256SUMS.txt` 提供下载校验值。

## 本版变化

- **店铺恐怖氛围重构**：将原本平亮的营业厅灯光改造为凌晨 2:30 病态暖黄旧荧光灯与暗影死角、冷柜冰蓝冷光、收银台孤立琥珀光，并加入室内高度雾与电影级恐怖后处理（低饱和度、高反差、灯管辉光、胶片颗粒与暗角）；全面 Shift 时应急灯转为深血红光并涌入暗红浓雾。
- **极简心理恐怖 UI**：全面替换科幻感方框与分段条，采用骨白／灰烬／干血红／烛火琥珀四色极简电影排布，配 3~5px 细线计量条、安静的 3px 骨白准星点，以及左下角用胶带贴住的泛黄员工便签纸《夜班异常守则》。
- **《夜班异常守则》与体态破绽推理**：移除准星低语剧透；玩家需用肉眼观察求助顾客的 3 种诡异体态（①歪头死盯空墙、②红眼微光+顶灯闪烁、③脚不沾地悬空漂浮），对照左下角守则递交对应克制商品即可平静驱离。
- **差异化追逐、双结局与手感升级**：第一晚第 3 位顾客即登场伪装怪客且每晚随机洗牌顺序与破绽；3 种怪客暴走后拥有不同猎杀行为（木头人背身加速、听冲刺脚步声狂暴、周期闪灯加速）；新增 `Left Shift` 冲刺与体力条、大幅缩短日常任务读条、距离动态双搏心跳声、双结局分支（完美守夜人 / 幸存夜班员），以及免编辑器外部 `.wav` 音效加载兜底。

## English quick start

Download **ShiftStore-v0.5-Windows-x64.zip**, extract the entire archive, and run **Windows/ShiftStore.exe**. Choose a language, then press Space, E, or Enter for a new game, or C to continue. This v0.5 build overhauls the store's late-night horror lighting, height fog, and filmic grading, introduces a minimalist psychological horror UI with the pinned Shift Rules memo, adds visual disguise tells, distinct entity pursuit behaviors, `[Shift]` sprint stamina, faster chores, and dual endings.

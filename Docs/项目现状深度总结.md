## 一、 参赛信息与核心立意（Game Jam 背景）

- **参赛活动**：**GitHub Game Off 2026**（为期约一个月的年度 Game Jam，通常于 12 月 1 日截止提交）。
- **比赛主题**：**`SHIFT`**
- **双关核心立意（Dual Meaning of SHIFT）**：
  1. **Night Shift（便利店夜班值守）**：玩家扮演 24 小时便利店的夜班店员，从深夜值守至次日清晨 `06:00 AM` 交班，在日常店务、营业额亏损上限（`-$40`）与精神清醒度（`Sanity 0~100%`）的双重压力下生存。
  2. **Spatial & Rule Shift（空间、商品与状态的异变转换）**：
     - **局部错位（Micro-Shift）**：日常值班时，店铺会发生局部空间/物件错位（迎宾牌篡改、货架暗移、冷柜震落商品）。
     - **全面异变（Store Shift）**：当伪装成顾客的异常实体（Entity）暴走显形时，整家便利店在运行时平滑切入异常状态——主照明熄灭仅留冷柜与安全出口冷光、中排货架横移改变通道、冷柜与干货架的商品类别发生空间对调。
     - **主动覆写与操作呼应（Breaker Override & `[Shift]` Sprint）**：玩家可按 `Left Shift` 键消耗体力冲刺拉扯，也可冲入后勤走廊拉下应急电闸，短暂将店铺从异常态强制覆写回正常照明与布局。

## 二、 玩法设计与核心循环（当前已实现）

当前版本为 **3 晚完整可玩原型（Night 1 → Night 2 → Night 3 → 结局）**，在 `feat/shift-gameplay` 分支中已由最初的“线性跑腿公式”升级为**“观察找茬 + 守则推理 + 并行抗压 + 空间博弈”**：

### 1. 基础循环与并行夜班压力
- **开店与日常店务**：包括补货（从仓库取货箱 `Stock Carton` 到指定货架）、清点库存、整理货架、倒垃圾、煮关东煮（`0.8~2.2 秒`快节奏读条）。每项任务有独立倒计时（三晚分别为 `240s / 180s / 120s`），逾期持续扣除清醒度，按时完成恢复清醒度。
- **顾客与局部异变并行（Micro-Shift Parallelism）**：
  - 店内同时接待 1 位顾客，但在顾客进店浏览或等待期间，店内会周期性突发**局部异变（`FixAnomaly`，限时 75 秒）**：迎宾牌被篡改为异常告示、二号货架偷偷横移、冷柜异响并震落商品。
  - 局部异变不阻塞后续顾客进店，迫使玩家在“盯紧店里的可疑顾客”和“去长按 `E` 复位店铺异变”之间做实时取舍；异变未及时处理会加速伪装怪客暴走。

### 2. 伪装怪客破绽观察与《夜班异常守则》推理
- **无剧透视觉找茬**：顾客求助找商品时，准星只显示其表面索要的商品（不再直白剧透真需求）。玩家必须在递交前**用肉眼观察顾客体态**，并核对屏幕左下角常驻的 3 条《夜班异常守则》：
  - **守则 ①【歪头死盯空墙（`HeadTilt`）】**（脖子歪斜 26° 且频繁扭头死盯空墙）→ 别给原商品，递交**【番茄浓汤罐头（`Can`）】**
  - **守则 ②【红眼微光+顶灯闪烁（`RedGlare`）】**（眼部渗出脉冲红光且头顶灯光周期性闪烁）→ 别给原商品，递交**【每日全脂鲜奶（`Milk`）】**
  - **守则 ③【脚不沾地悬空漂浮（`Floating`）】**（脚底离地约 22 cm 上下悬浮晃动）→ 别给原商品，递交**【晨光切片面包（`Bread`）】**
- **两种结果分流**：
  - **识破平静驱离（Ward Off）**：在怪客显形前递交守则对应的克制商品，怪客会低语离店，**不触发全店熄灯 Shift**，玩家获得 **+$10.00 识破奖金与 +8 清醒度**。
  - **触发禁忌当场暴走（Full Shift）**：若玩家没看破伪装、把表面索要的商品递给了怪客，或贴脸（`< 155 cm`）直视过久，或超过其潜伏耐性（`13~17 秒`），怪客当场暴走显形并触发全面 Shift。
- **首夜见真章与随机洗牌（防背板）**：
  - 第一晚第 3 位顾客即登场伪装怪客；每次开局或重开夜晚，系统自动打乱后续顾客登场顺序，并随机洗牌怪客的视觉破绽类型与对应克制商品。

### 3. 全面 SHIFT 空间博弈与反制逃生
- **货架商品真错位（Stock Swap）+ 脉冲寻物**：
  - 全面 Shift 期间，冷柜与干货架的商品类别发生空间互换（水 ↔ 罐头、鲜奶 ↔ 酱油、汽水 ↔ 面包、泡面 ↔ 便当、薯片 ↔ 饼干、纸巾 ↔ 清洁剂）。玩家既可凭记忆直接去错位货架拿取怪物执念商品，也可循着微弱呼吸红光（半径 75 cm）与 3D 方位脉冲音在角落找到散落需求物，交到收银台驱离怪物。
- **后勤走廊应急电闸（Emergency Breaker）**：
  - Shift 熄灯期间，玩家可冲进后勤走廊按 `E` 拉下电闸，**强制恢复全店正常照明与货架位置 10 秒**，并让怪物被强光短暂硬直 1.4 秒；代价是电弧噪音会**把怪物的搜寻目标直接引向后勤走廊**。
- **`[Shift]` 键冲刺、投掷眩晕与被抓挣脱**：
  - 按住 `Left Shift` / `Right Shift` 消耗体力高速冲刺（`285 → 435 cm/s` + FOV 动态拉宽）。
  - 可拿起任意商品或关东煮热汤杯按 `F` / `右键` 投掷砸晕怪物（不同商品有不同眩晕时长与成本价，损坏商品计入店铺亏损，超过 `-$40` 淘汰）。
  - 被抓时镜头锁定怪物面部，可连按 `E` 缓慢挣脱，或手持商品按 `F` / `右键` 直接砸晕瞬间脱身。
- **商品归位与夜末收尾清理**：
  - 拿取的商品可对准任意货架/冷柜按 `E` 无损放回；当晚所有顾客服务完毕后，去仓库拿拖把（`Mop`）清理地面污渍并将所有散落商品放回货架，即可迎来 `06:00 AM` 天亮并自动存档。

## 四、 目前存在的缺陷与短板（客观盘点）

尽管玩法闭环和自动化测试已经非常扎实，但作为一款冲刺 Game Jam 评审的**第一人称恐怖游戏**，目前仍有以下明显短板：

### 1. 角色与怪物美术表现为“引擎模板白模”（最直观短板）
- **现状**：正常顾客和显形后的怪物均使用 UE5 官方模板人偶 `SKM_Manny_Simple` + 基础无武装走跑动画（`ABP_Unarmed`）。怪物显形只是将全身材质替换为深炭色（`M_Charcoal`）、拉高身体比例（`0.92 × 0.92 × 1.18`）并点亮眼部红光。
- **影响**：缺少真正的恐怖五官、便利店顾客服装差异和诡异肢体动画。被怪物抓住贴脸（Grab Camera）时，玩家看到的是一个黑灰色的 UE 默认假人头，惊悚感大打折扣。

### 2. 音频系统全靠代码合成正弦波（缺乏真实环境沉浸感）
- **现状**：目前工程内没有任何外部 `.wav` 真实录音素材；冰柜嗡嗡声、门铃、任务完成音、心跳声、异常脉冲和惊吓音全部由 `USoundWaveProcedural` 在 C++ 中用正弦波叠加白噪声实时生成。
- **影响**：虽然程序化双搏心跳声和低频嗡鸣能提供基础节奏，但缺少写实的**便利店迎宾电子门铃、塑料袋摩擦声、货架后沉重的脚步声、急促喘息声、日光灯管电流滋滋声**，难以达到参考目标《诡租：205号房》的写实声场质感。

### 3. 怪物追逐阶段的 AI 行为模式仍偏单一
- **现状**：虽然显形前有 3 种不同的视觉破绽（歪头、红眼、悬浮），但一旦玩家失误触发全面 Shift 暴走后，所有怪物的追逐逻辑都是同一套“巡逻 → 视线看到玩家以 `248 cm/s` 追击 → 距离 `< 92 cm` 抓取”。
- **影响**：玩家熟悉地形后，在 Shift 阶段只需利用 `285 / 435 cm/s` 的移速优势绕着中排货架转圈（Looping），怪物较难给老手制造不可预测的走位压迫（例如缺少“盯着不动、转头瞬移逼近”或“听脚步声冲锋”的差异化猎杀机制）。

### 4. 剧情叙事与结局厚度不足
- **现状**：目前仅有每晚开场的 2 行简短交班提示（Night Intro）和第三晚结束后的通关结算画面（Ending），原本策划讨论的“7 晚递进”目前浓缩为 3 晚 MVP。
- **影响**：缺乏为什么这家 24 小时便利店会发生空间 Shift、白班店员留下了什么秘密、以及根据玩家三晚表现（比如“零失误全部识破驱离” vs “多次触发 Shift 狼狈逃生”）触发**多结局分支**的叙事回味。

### 5. 外部交付与真人盲测尚未闭环
- **现状**：
  - GitHub 远端 `origin/main` 和 Release 页面仍停留在旧版 `v0.2`（`e50bec2`），本地 `main` 分支的修复和 `feat/shift-gameplay` 分支的玩法大改尚未合并推送及打包发布 `v0.3 / v0.4`。
  - 工作区 `Config/DefaultEngine.ini` 仍有 15 行未清理的 `AndroidFileServer` 插件残留改动。
  - 尚未在“未安装 UE5 / Python 的纯净 Windows 电脑”上由未看过策划的真人玩家完成完整三晚盲测。

## 五、 距离比赛截止前的优先级建议

1. **第一优先级（真人试玩调优 & 合并主分支发版）**：
   - 你亲自在当前 `Builds/Windows/启动正常场景.cmd` 试玩 1~2 局 `feat/shift-gameplay` 分支，确认左下角《夜班异常守则》、3 种肉眼破绽、Shift 冲刺手感和任务读条节奏是否满意。
   - 满意后将 `feat/shift-gameplay` 合并入 `main`，清理 `DefaultEngine.ini`，推送到 GitHub 并发布新版 Release 下载包。
2. **第二优先级（高性价比音画提振——由团队美术/音乐并行介入）**：
   - **音频替换**：接入 5~8 个高质感 CC0/原创音效（真实便利店门铃、怪物沉重脚步、呼吸声、日光灯镇流器电流声、收银机扫码滴声）。
   - **怪物外观**：哪怕只替换怪物头部网格体或贴一张高对比度恐怖面部贴图/扭曲材质，都能让被抓贴脸瞬间的视觉冲击力翻倍。
3. **第三优先级（差异化追逐行为与双结局收尾）**：
   - 为 3 种破绽的怪客在暴走后赋予 1 个差异化追逐特性（如悬浮怪客在玩家背对它时移速翻倍、红眼怪客会周期性熄灭冷柜灯）。
   - 增加简短的“完美值班员（全部识破）”与“幸存夜班员”双结局文本，锁死 **精品 3 晚（或扩展至 4~5 晚）** 规模，留足最后 2~3 天制作 itch.io 页面截图与宣传 GIF。

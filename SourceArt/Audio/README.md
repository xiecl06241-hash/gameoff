# 音效候选素材

本目录包含 Sound.zip 中的 25 个原始音频和原始来源清单。音频内容保持原样，解压后逐个核对 SHA-256 与压缩包内文件一致。

这些素材供试听和审核，尚未接入 UE 工程，也未进行游戏内测试。WAV、MP3、M4A 使用 Git LFS 存储。

## 授权审核待办

- 来源清单 366788（gidion，owi-box-falling-on-ground.wav）的页面标注 CC BY-NC 3.0。
- 来源清单 680983（logicmoon，crossings.wav）的页面标注 CC BY-NC 4.0。
- 上述两项限制商业用途，合并或发行前需要确认用途是否符合许可、取得补充授权或替换素材。
- 435289（zazzsounddesign，cloth-rustle-3.wav）的页面此次未返回可识别的许可证，需要人工确认。
- 本地文件经过中文重命名，原始清单没有逐项记录与本地文件的对应关系，需由提交者确认。文件名中的“可商用”和作者文字仍需与来源页面核对。
- CC BY 素材需在确定本地文件对应关系后，整理作者、作品名、来源、许可证和修改记录用于发行署名。
